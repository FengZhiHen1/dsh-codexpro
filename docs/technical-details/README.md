# dsh-codexpro 技术细节

## 权威范围

本文是 `dsh-codexpro` 技术细节目录的入口，唯一拥有本目录的阅读顺序与文档地图。机制事实归各机制文档；本文不重复定义机制。

## 阅读顺序

1. `配置与profile投影.md`：先读配置 schema 形状、锚点与数据目录、profile 文件的生成与写入语义。
2. `进程管理.md`：再读 codexpro 进程的启动、状态机、健康探测、终止与残留防护。
3. `RPC通道与设置页.md`：最后读 Client↔Host 传输契约与设置页接入方式。

## 文档地图

| 文档 | 唯一权威范围 |
|------|--------------|
| `配置与profile投影.md` | 配置字段表与 volatile 形状约束、校验规则、锚点与数据目录推导、profile 文件身份与 payload 形状、原子写与单向同步、候选集推导与不变量 |
| `进程管理.md` | 宿主进程能力边界、环境清洗陷阱、可执行解析、启动参数与 spawn 规格、健康探测、状态机、终止分层防线与防残留规则、失败语义 |
| `RPC通道与设置页.md` | `/api` 精确 Fetch 路由形态与约束、端点清单与载荷、信封契约与错误码、Client 调用形态、slot 与 key 约定、页面三区与 UI 原语 |
